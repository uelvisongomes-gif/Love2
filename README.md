# LOVE Casal — Web

Next.js 15 frontend for the LOVE Casal backend.

## Development

```
npm install
cp .env.local.example .env.local
# backend must be running at http://localhost:3000
npm run dev
```

Open http://localhost:3001

## Backend

Backend repo lives in the adjacent `LOVEMEDIADOR/` folder. Run `npm run dev` there first.
